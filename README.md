# Laboratorio 11 Firebase

Aplicación Make It So con Kotlin y Jetpack Compose, basada en el proyecto de BparejaTec/Lab11_Start.

La solución implementa vinculación de cuentas anónimas, estado reactivo de autenticación, tareas de Firestore por usuario y opciones de edición. Incluye reglas de propiedad de documentos, Remote Config y trazas de rendimiento.

**Antes de ejecutar:** crea tu proyecto de Firebase, habilita Email/Password y Anonymous, publica `firestore.rules` y coloca tu archivo `google-services.json` en `start/app/`.

Abre `start/` en Android Studio y selecciona JDK 17 y la variante devDebug.

Consulta [LEEME_PRIMERO.md](LEEME_PRIMERO.md) para la configuración completa, pruebas, publicación del repositorio y guion del video. Las evidencias funcionales requieren conectar Firebase y ejecutar la app.
